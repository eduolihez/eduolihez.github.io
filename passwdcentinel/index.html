Preguntas Frecuentes

Todo lo que necesitas saber sobre Password Sentinel

¿Es realmente gratuito?

+

Sí, Password Sentinel es completamente gratuito. No tenemos planes de pago, suscripciones ni versiones premium. Creemos que la seguridad básica debería ser accesible para todos.

¿Mis contraseñas son seguras?

+

Absolutamente. Tus contraseñas nunca salen de tu dispositivo. El análisis de brechas usa k-anonymity, enviando solo un hash parcial que no puede ser revertido a tu contraseña original.

¿Funciona en todos los sitios web?

+

Sí, Password Sentinel funciona en cualquier sitio web que tenga campos de contraseña. Se integra discretamente sin afectar el funcionamiento normal de las páginas.

¿Puedo usar la extensión en modo incógnito?

+

Sí, pero necesitas activar manualmente el permiso para modo incógnito en la página de extensiones de Chrome. Es un proceso simple de un solo paso.
