Política de Privacidad

🔐 Compromiso de Privacidad

Password Sentinel ("nosotros", "nuestro" o "la extensión") está comprometida con proteger tu privacidad. Esta política explica cómo manejamos tu información cuando usas nuestra extensión de Chrome.

📊 Información que NO Recopilamos

NO recopilamos, almacenamos ni transmitimos:

  • ❌ Contraseñas que analices o generes
  • ❌ Información personal identificable
  • ❌ Historial de navegación
  • ❌ Datos de formularios o sitios web
  • ❌ Direcciones IP o información de localización
  • ❌ Identificadores de dispositivo

💾 Almacenamiento Local

La extensión utiliza el almacenamiento local de tu navegador para:

  • ✅ Configuración de preferencias del usuario
  • ✅ Historial opcional de contraseñas generadas (si activas esta opción)
  • ✅ Ajustes personalizados de seguridad

Todos estos datos permanecen exclusivamente en tu dispositivo y nunca se transmiten externamente.

🌐 Uso de Servicios Externos

API de Have I Been Pwned:

  • ✅ Solo para verificación de brechas de seguridad
  • ✅ Usamos el método k-anonymity (privacidad por diseño)
  • ✅ Solo enviamos los primeros 5 caracteres del hash SHA-1 de tu contraseña
  • ✅ Nunca enviamos contraseñas completas o texto plano
  • ✅ Esta funcionalidad es opcional y puedes desactivarla

🔒 Seguridad de Datos

Implementamos las siguientes medidas de seguridad:

  • 🔒 Procesamiento local de todas las contraseñas
  • 🔒 Cifrado de datos almacenados localmente
  • 🔒 Sin servidores externos para el procesamiento principal
  • 🔒 Transmisión segura (HTTPS) para verificaciones de brechas

📈 Mejora de la Extensión

Para mejorar la experiencia del usuario, podemos recopilar:

  • ⚙️ Estadísticas anónimas de uso (funcionalidades más utilizadas)
  • 🔧 Información de errores y rendimiento (sin datos personales)
  • 💡 Sugerencias de mejora (opcionales, proporcionadas por ti)

🚫 Compartición con Terceros

NO compartimos tu información con:

  • ❌ Empresas de publicidad
  • ❌ Redes sociales
  • ❌ Servicios de analytics de terceros
  • ❌ Socios comerciales

Excepción: Solo interactuamos con la API de Have I Been Pwned usando el método seguro descrito anteriormente.
